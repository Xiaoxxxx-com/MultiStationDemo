# 模块编写规则

适用范围：所有继承 `ModuleBase` 的模块及其子类。核心原则是「一个模块总类 + 若干部分子类」。

## 一、结构

| 编号 | 规则 | 说明 | 级别 |
|---|---|---|---|
| M-01 | 一个模块只有一个总类 | 总类实现 `IModule`（经 `ModuleBase`），命名 `<模块名>Module`，是外部唯一可引用类型 | 阻断 |
| M-02 | 总类固定骨架 | 生命周期、信封校验、身份与优先级校验、幂等去重、异常兜底、计时统计、主题分派、审计写入 | 阻断 |
| M-03 | 按部分拆子类 | 命令、查询、事件投影、序列、设备会话、健康探针、指标、恢复各自一个 Part 子类 | 强制 |
| M-04 | 一个子类只承担一个部分 | 单一职责，不得同时处理命令与查询 | 强制 |
| M-05 | 子类之间不互相引用 | 通过总类暴露的受保护成员与 `ModuleContext` 交互 | 阻断 |
| M-06 | 总类聚合子类 | 总类持有子类列表并在构造中 `RegisterPart(topic, part)` 建立路由表 | 强制 |

## 二、模板方法

| 编号 | 规则 | 说明 | 级别 |
|---|---|---|---|
| M-07 | 模板方法不可重写 | `StartAsync` / `StopAsync` / `HandleAsync` / `ResolvePart` 固定，子类不得重写 | 阻断 |
| M-08 | 子类只实现三个钩子 | `OnStartAsync` / `OnStopAsync` / `OnMessageAsync` | 强制 |

模板方法执行顺序固定为：校验 → 幂等去重 → 分派 Part → 异常兜底 → 计时上报。任何子类都不得改变这个顺序。

## 三、职责边界

| 编号 | 规则 | 说明 | 级别 |
|---|---|---|---|
| M-09 | 接口层不写业务逻辑 | Part 只做参数校验、用例调用、结果组装 | 强制 |
| M-10 | 子类不得持有其他模块引用 | 只允许通过 `Owner` 与 `Context` 交互 | 阻断 |
| M-11 | 子类不得自建线程或后台任务 | 定时器必须在 `OnStopAsync` 中释放 | 强制 |
| M-12 | 子类不得绕过总类 | 不得自行拼 target 发消息、不得自行提升优先级、不得吞异常 | 阻断 |

回复一律使用 `Context.ReplyAsync(correlationId, body, priority, ct)`，不允许手工构造 `replyTo`。

## 四、规模与依赖

| 约束 | 数值 | 说明 |
|---|---|---|
| 单个 Part 行数 | ≤ 300 行 | 超出即继续拆分 |
| 单个总类行数 | ≤ 200 行 | 只放骨架与路由 |
| 子类构造参数 | 只接收总类实例 | 不接收 `IServiceProvider` 或全局单例 |
| 跨部分字段改动 | 经总类方法 | 不得直接改另一 Part 负责的字段 |

## 五、代码骨架

```csharp
public abstract class ModuleBase : IModule
{
    private readonly List<IModulePart> _parts = new();
    private readonly Dictionary<string, IModulePart> _routes = new(StringComparer.Ordinal);

    protected IModuleContext Context { get; private set; } = null!;

    public abstract ModuleDescriptor Descriptor { get; }

    // 模板方法：固定顺序启动，失败回滚
    public async Task StartAsync(IModuleContext context, CancellationToken ct)
    {
        Context = context;
        var started = new List<IModulePart>();
        try
        {
            foreach (var part in _parts)
            {
                await part.OnStartAsync(ct);
                started.Add(part);
            }
        }
        catch
        {
            foreach (var part in Enumerable.Reverse(started))
                await part.OnStopAsync(CancellationToken.None);
            throw;
        }
    }

    // 模板方法：逆序停止，单个失败不影响其他
    public async Task StopAsync(CancellationToken ct)
    {
        foreach (var part in Enumerable.Reverse(_parts))
        {
            try { await part.OnStopAsync(ct); }
            catch (Exception ex) { Context.Log.Warn(Descriptor.ModuleId, "part stop failed", ex); }
        }
    }

    // 模板方法：校验 → 去重 → 分派 → 兜底 → 计时
    public async ValueTask HandleAsync(MessageEnvelope message, CancellationToken ct)
    {
        var startedAt = System.Diagnostics.Stopwatch.GetTimestamp();
        try
        {
            if (!TryValidate(message, out var reason))
            {
                await RejectAsync(message, reason!, ct);
                return;
            }

            if (await TryGetDuplicateAsync(message, ct) is { } duplicate)
            {
                await ReplyDuplicateAsync(message, duplicate, ct);
                return;
            }

            var part = ResolvePart(message.Header);
            await part.OnMessageAsync(message, ct);
        }
        catch (OperationCanceledException)
        {
            await ReplyCancelledAsync(message, ct);
        }
        catch (Exception ex)
        {
            await OnUnhandledAsync(message, ex, ct);
        }
        finally
        {
            ReportCost(message, startedAt);
        }
    }

    protected void RegisterPart(string topic, IModulePart part)
    {
        _parts.Add(part);
        _routes[topic] = part;
    }

    protected abstract bool TryValidate(MessageEnvelope message, out string? reason);
    protected abstract ValueTask OnUnhandledAsync(MessageEnvelope message, Exception ex, CancellationToken ct);
}
```

```csharp
public sealed class StationModule : ModuleBase
{
    public StationModule(string stationId, StationOptions options)
    {
        State = new StationState(stationId, options);

        RegisterPart(Topics.Station.Start, new StationCommandPart(this));
        RegisterPart(Topics.Station.Snapshot, new StationQueryPart(this));
        RegisterPart(Topics.Device.StateChanged, new StationEventPart(this));
        RegisterPart(Topics.Dispatch.WorkArrived, new StationSequencePart(this));
        RegisterPart(Topics.Station.Tick, new StationMetricsPart(this));
    }

    public StationState State { get; }

    public override ModuleDescriptor Descriptor => new(
        ModuleId: $"station.{State.StationId}",
        Subscriptions: new[] { Topics.Station.Start, Topics.Station.Snapshot, Topics.Device.StateChanged },
        Dependencies: Array.Empty<string>(),
        RequiredResources: new[] { "config.recipe" },
        Capabilities: new[] { "station.sequence" },
        Mailbox: new MailboxOptions(),
        IsCritical: true);

    protected override bool TryValidate(MessageEnvelope message, out string? reason)
    {
        reason = message.Body.Length > MessageLimits.HardLimit ? ErrorCodes.MsgTooLarge : null;
        return reason is null;
    }

    protected override ValueTask OnUnhandledAsync(
        MessageEnvelope message, Exception ex, CancellationToken ct)
        => Context.Log.ErrorAsync(Descriptor.ModuleId, message.Header.Topic, ex, ct);
}
```

## 六、检查清单

- [ ] 模块只有一个继承 `ModuleBase` 的总类
- [ ] 总类只有骨架与路由表，没有具体业务分支
- [ ] 每个部分独立为 Part 子类，未与其他 Part 互相引用
- [ ] 子类只实现 `OnStart` / `OnStop` / `OnMessageAsync`
- [ ] 新增部分只需新增一个子类 + 一行 `RegisterPart`
- [ ] 子类未超过 300 行、未承担两个以上职责
- [ ] 回复统一走 `Context.ReplyAsync`
- [ ] 停止路径释放了子类创建的定时器与作业
