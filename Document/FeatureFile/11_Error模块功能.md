# Error 模块功能

- 顶层模块：`MultiStation.Error`
- 子模块：`MultiStation.Error.Health`、`.Recovery`
- 合并依据：看门狗、自检、降级、报警都在回答同一个问题——系统还正不正常
- 功能编号段：F-ERR-01 ~ F-ERR-06

## 一、功能清单

| 编号 | 功能 | 说明 | 依赖 | 状态 |
|---|---|---|---|---|
| F-ERR-01 | 看门狗 | 监控主循环、设备心跳、界面刷新，超时即告警 | Core 指标 | 规划 |
| F-ERR-02 | 启动自检 | 仪器连通、配置完整性、安全状态、版本一致性 | Device、Config、Safety | 规划 |
| F-ERR-03 | 降级决策 | 依据资源可用性把模块置 Degraded，路由期快速失败 | Core 资源表 | 规划 |
| F-ERR-04 | 报警管理 | 报警产生、分级、确认、恢复，统一出口 | Data 报警表、Ui | 规划 |
| F-ERR-05 | 故障隔离与恢复 | 单设备/单模块故障不扩散，支持单独重启 | Core 生命周期 | 规划 |
| F-ERR-06 | 健康上报 | 汇总各模块健康与负载，输出整机健康视图 | 全部模块 | 规划 |

## 二、关键规则

| 规则 | 内容 |
|---|---|
| 报警不单独成模块 | 报警属于 Error 的一部分，禁止再拆出独立顶层模块 |
| 分级 | 提示 / 警告 / 错误 / 安全，安全级联动 Safety |
| 降级判据 | 由 `RequiredResources` 声明，Core 路由期判定，不靠模块内部 if |
| 自检失败 | 任一项失败则禁止进入自动模式，仅允许诊断模式 |
| 停机 | StopAsync 5s 超时强制取消，记录未处理消息数 |

## 三、验收标准

| 编号 | 场景 | 期望 |
|---|---|---|
| A-01 | 断开一台相机 | 自检失败，提示仪器离线清单，禁止自动运行 |
| A-02 | 某设备心跳丢失 3 次 | 产生设备失联报警，相关工位转 Error，其他工位继续 |
| A-03 | PLC 共享设备故障 | 停止投料，在制品完成当前步骤后暂停 |
| A-04 | 模块停止超 5s | 强制取消并记录未处理消息数 |
| A-05 | 报警确认 | 记录确认人与时间，未恢复前不可消除 |
