# Device 模块功能

- 顶层模块：`MultiStation.Device`
- 子模块：`.Parts`、`.Adapters`（`.Modbus` / `.Scpi` / `.Can`）
- 合并依据：PLC、相机、仪表、机器人共用「独占外设 + 统一会话」，不可再拆
- 功能编号段：F-DEV-01 ~ F-DEV-06

## 一、功能清单

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| F-DEV-01 | 会话管理 | 打开、关闭、健康探针、故障隔离与重连 | 规划 |
| F-DEV-02 | PLC 接入 | Modbus TCP 点位读写、握手字等待、批量下发 | 规划 |
| F-DEV-03 | 相机接入 | 触发拍照、曝光增益设置、图像句柄返回 | 规划 |
| F-DEV-04 | 仪表接入 | SCPI 设压设流、回读电压电流、OVP 设置 | 规划 |
| F-DEV-05 | 机器人/总线接入 | CAN / DBC 编解码、XCP 标定 | 规划 |
| F-DEV-06 | 来源公平与批量 | 多工位共享设备按来源 WFQ；连续点位合并为批命令 | 规划 |

## 二、关键规则

| 规则 | 内容 |
|---|---|
| 独占 | 一台相机绑定一个工位，注册表校验 `owner` 唯一 |
| 共享 | PLC、电源等由多工位共享，设备内部单队列串行，按来源公平轮转 |
| 超时 | 连接超时、单次响应超时、整体命令超时三级 |
| 幂等 | 仅幂等命令允许重试；写输出类命令不重试 |
| 批量 | 连续点位用 `executeBatch`，禁止逐点位一条消息 |
| 大负载 | 图像走共享缓冲 + `BufferHandle`，消息体只传句柄 |

## 三、验收标准

| 编号 | 场景 | 期望 |
|---|---|---|
| A-01 | 单设备读写 | 命令成功率 ≥ 99%，连续 1 小时无泄漏 |
| A-02 | 拔网线 | 设备转 Fault，未完成命令返回失败，重连后恢复 |
| A-03 | 两工位争用 PLC | 等待时间偏差 ≤ 20%，无饿死 |
| A-04 | 采集一张图像 | 消息体 ≤ 100 字节（句柄），图像零拷贝读取 |
| A-05 | 写入超时 | 按重试次数重发，耗尽返回 `DEV_TIMEOUT` |
