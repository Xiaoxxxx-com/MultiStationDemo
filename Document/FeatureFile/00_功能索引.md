# 功能文档索引

本目录用于功能开发的落档。规则：**先落档、再开发、验收后冻结**。

## 一、落档要求

| 项 | 要求 |
|---|---|
| 文件位置 | `Document/FeatureFile/` |
| 文件格式 | Markdown（.md） |
| 命名规则 | `<两位序号>_<功能名>.md`，模块级文档为 `<序号>_<模块名>模块功能.md` |
| 必备章节 | 功能编号、功能描述、输入输出、依赖、验收标准、状态 |
| 功能编号 | `F-<模块缩写>-<序号>`，如 `F-SEC-01`、`F-TST-03` |
| 状态取值 | 规划 / 开发中 / 待验收 / 已验收 / 已废弃 |
| 变更要求 | 实现与文档不一致时以文档为准，先改文档再改代码，并在变更记录中登记 |
