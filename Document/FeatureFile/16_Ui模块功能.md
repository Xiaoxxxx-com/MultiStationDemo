# Ui 模块功能

- 顶层模块：`MultiStation.Ui`
- 子模块：`.Views`、`.ViewModels`、`.Desktop`、`.Demo`
- 职责：看板、序列编辑器、配方界面、报表、报警中心、登录与锁屏、桌面外壳
- 功能编号段：F-UI-01 ~ F-UI-09

## 二、关键规则

| 规则 | 内容 |
|---|---|
| 只读快照 | 界面只读模块快照，不直接访问业务对象 |
| 非阻塞 | 界面投递使用 `TrySend`，禁止因背压卡住 UI 线程 |
| 权限 | 操作类按钮受 `RequirePermission` 拦截，无权限弹提示 |
| 合并刷新 | Background 事件按帧合并，避免高频重绘 |
| 版本一致 | 事件版本跳号时主动 Query 快照并 resync |

## 三、验收标准

| 编号 | 场景 | 期望 |
|---|---|---|
| A-01 | 启动 | 授权 → 登录 → 主界面，标题显示账号与剩余天数 |
| A-02 | Operator 点击字段配置 | 提示权限不足，不弹出菜单 |
| A-03 | 事件丢失 | 2 秒内通过快照 resync 恢复正确显示 |
| A-04 | 高频指标刷新 | 界面不卡顿，CPU 占用平稳 |
| A-05 | 关闭窗口 | 停止产线、释放设备、退出进程 |
| A-06 | 测试开始 | 基础信息区生成 SN（`SN`+时间戳）与 CarrierID（`CAR`+时分秒），并刷新工单、配方、操作员、开始时间；未开始时 SN/CarrierID 显示 `-` |

## 五、验证记录

基础信息取值逻辑已抽到 `MultiStation.Ui.Desktop/BasicUnitInfo.cs`，单元测试位于 `tools/MultiStation.Ui.UnitTests`，不启动界面即可运行：

```powershell
& "$env:USERPROFILE\.dotnet\dotnet.exe" run --project tools\MultiStation.Ui.UnitTests\MultiStation.Ui.UnitTests.csproj
```

| 编号 | 场景 | 期望 | 实测 |
|---|---|---|---|
| BI-01 | 未开始测试 | SN / CarrierID / 开始时间为 `-`，工单与配方已就绪 | 通过 |
| BI-02 | 新件开始 | `SN+yyyyMMddHHmmss`、`CAR+HHmmss`，个位补零 | `SN20260102030405 / CAR030405` |
| BI-03 | 工单号 | `MO+yyyyMMdd` | `MO20260102` |
| BI-04 | 配方映射 | A→`A（串行）`，B→`B（并行）` | 通过 |
| BI-05 | 操作员与开始时间 | 原样透传操作员，开始时间 `HH:mm:ss` | `op01（Operator） / 03:04:05` |
| BI-06 | 连续两件 | SN / CarrierID 不重复 | 通过 |
| BI-07 | 初始与开始后工单一致 | 同一时刻工单号相同 | 通过 |

界面侧由冒烟套件 U-CF01 断言：确认开始后基础信息区出现 `SN… / CAR…`。
