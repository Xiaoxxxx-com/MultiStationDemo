# Data 模块功能

- 顶层模块：`MultiStation.Data`
- 子模块：`.Persistence`（`.Wal` / `.Audit`）、`.Telemetry`（`.Logs` / `.Metrics`）
- 合并依据：结果、明细、日志、死信、报表全是写盘与查盘，共用一套库与一套迁移
- 功能编号段：F-DAT-01 ~ F-DAT-07

## 一、功能清单

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| F-DAT-01 | 结果落库 | 单件 UnitResult 与阶段 StageResult 落库 | 规划 |
| F-DAT-02 | 步骤明细 | StepResult 与测量值（含阈值、单位）落库 | 规划 |
| F-DAT-03 | 遥测日志 | 结构化日志按天轮转，保留期可配 | 规划 |
| F-DAT-04 | 死信归档 | 无法投递与处理失败的消息归档并可重放 | 规划 |
| F-DAT-05 | 报表查询 | 按时间段、配方、工位统计良率与节拍 | 规划 |
| F-DAT-06 | SPC 查询 | 参数趋势、CPK、超限分布 | 规划 |
| F-DAT-07 | WAL 与重放 | 写前日志，崩溃重启按幂等键重放，不丢不重 | 规划 |

## 二、关键规则

| 规则 | 内容 |
|---|---|
| 同事务 | checkpoint 与结果同事务提交，避免「结果写了进度没写」 |
| 幂等 | 幂等键持久化，重放返回首次结果，不重复产生副作用 |
| 保留期 | 结果按项目保留期归档，日志按天轮转并定期清理 |
| 丢弃策略 | 结果类不得丢弃；日志类在积压时可丢弃并计数 |
| 审计独立 | 审计表独立于结果表，不受遥测丢弃策略影响 |

## 三、验收标准

| 编号 | 场景 | 期望 |
|---|---|---|
| A-01 | 测试 1000 件 | 结果与明细条数一致，无重复 |
| A-02 | 落库过程中断电 | 重启后重放未提交记录，结果数不丢不重 |
| A-03 | 按工件号查询 | 返回全部步骤、测量值、判定与耗时 |
| A-04 | 磁盘水位超阈值 | 告警并降级为只写关键结果，不阻塞产线 |
| A-05 | 死信重放 | 人工触发，按时间窗重放，结果写审计 |
