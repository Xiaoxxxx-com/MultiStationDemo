# Platform 模块功能

- 顶层模块：`MultiStation.Platform`
- 子模块：`.Contracts`、`.Core`、`.Config`、`.Host`、`.Simulation`、`.Security`
- 合并依据：配置、配方、版本、权限、审计都属于低频写高频读的静态数据，一个加载缓存即可服务全部
- 功能编号段：F-PLT-01 ~ F-PLT-08

## 一、功能清单

| 编号 | 功能 | 说明 | 子模块 | 状态 |
|---|---|---|---|---|
| F-PLT-01 | 消息契约 | 信封、三级优先级、四类消息语义、Topic 常量 | Contracts | 规划 |
| F-PLT-02 | Core 总线 | 注册、路由、三级队列、超时取消、身份覆盖、指标 | Core | 规划 |
| F-PLT-03 | 配置中心 | 设备描述、阈值、系统参数的加载与热更新 | Config | 规划 |
| F-PLT-04 | 配方与版本 | 配方定义、版本号、变更审计与回滚 | Config | 规划 |
| F-PLT-05 | 序列定义 | 测试序列的加载、校验与版本管理 | Config | 规划 |
| F-PLT-06 | 权限与审计 | 登录、角色、权限点、审计事件流 | Security | 已验收（登录/权限） |
| F-PLT-07 | 组合根 | 模块装配、启动顺序、停机顺序 | Host | 规划 |
| F-PLT-08 | 仿真 | 设备与产线仿真，支持故障注入与回放 | Simulation | 规划 |

## 二、关键规则

| 规则 | 内容 |
|---|---|
| 单向依赖 | 业务模块只依赖 Platform 的契约与核心，反向禁止 |
| 配置校验 | 启动前完整校验引用、阈值、变量、设备能力，失败拒绝运行 |
| 热更新 | 预览 + 生效两步，在工位空闲边界切换 |
| 版本 | 契约、配置、序列、配方均带版本号，结果记录写入序列版本 |
| 身份 | source 由 Core 覆盖；关键命令写审计流 |

## 三、验收标准

| 编号 | 场景 | 期望 |
|---|---|---|
| A-01 | 配置缺字段 | 启动校验失败，列出缺失项，拒绝进入自动模式 |
| A-02 | 序列引用不存在的设备 | 校验失败并定位到具体步骤 |
| A-03 | 运行中修改阈值 | 预览差异，确认后在空闲边界生效，写审计 |
| A-04 | 越权发送 Control 命令 | Core 拒绝并记 `AUDIT_DENIED` |
| A-05 | 停机 | 按「停投料 → 排空 → 停设备 → 冲刷 → 退出」顺序 |
