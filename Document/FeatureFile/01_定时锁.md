# 定时锁（授权到期锁定）

- 所属模块：`MultiStation.Platform`（子模块 `MultiStation.Platform.Security`）
- 功能编号段：F-LIC-01 ~ F-LIC-05
- 当前状态：已验收

## 一、功能清单

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| F-LIC-01 | 启动授权校验 | 启动时读取授权文件，未通过则不进入主界面，仅显示锁定窗口 | 已验收 |
| F-LIC-02 | 到期锁定 | 当前时间 ≥ 到期时间即锁定，显示到期时间与续期方式 | 已验收 |
| F-LIC-03 | 试用期 | 首次运行自动生成 30 天试用授权，状态标记为「试用」 | 已验收 |
| F-LIC-04 | 到期提醒 | 剩余天数 ≤ 15 天时状态为「即将到期」，主界面标题显示剩余天数 | 已验收 |
| F-LIC-05 | 时间回拨检测 | 当前时间早于上次运行时间超过 10 分钟，判定授权异常并锁定 | 已验收 |

## 二、规则

| 项 | 规则 |
|---|---|
| 授权文件 | `license.json`，字段 `ExpiresAt` / `TrialDays` / `ExpiringWarningDays` / `ClockRollbackToleranceMinutes` |
| 存放位置 | 优先 `%LocalAppData%\MultiStationDemo\security`；不可写时回退程序目录、临时目录 |
| 时钟文件 | `lastseen.json` 记录上次运行时间，用于回拨检测 |
| 锁定行为 | 只显示 `LicenseWindow`，不创建主窗口、不启动产线，退出码 0 |
| 续期方式 | 修改 `ExpiresAt` 后重启软件，无需重新安装 |
| 不可绕过 | 锁定判断在 `App.OnStartup` 的最前段，早于任何业务初始化 |

## 三、输入输出

| 方向 | 内容 |
|---|---|
| 输入 | `license.json`、系统时间、`lastseen.json` |
| 输出 | `LicenseInfo`（状态、到期时间、剩余天数、提示语） |
| 副作用 | 首次运行创建授权文件；每次启动刷新 `lastseen.json` |

## 四、状态机

```
缺失 → 创建试用(30天)
试用/有效 → 剩余>15天：有效
        → 剩余≤15天：即将到期
        → 到期：已过期（锁定）
时间回拨 → 授权异常（锁定）
```

## 五、验收标准

| 编号 | 场景 | 期望 |
|---|---|---|
| A-01 | 首次运行 | 自动生成 30 天试用，正常进入登录 |
| A-02 | 到期日当天之后启动 | 显示「已过期」锁定窗口，无法进入主界面 |
| A-03 | 剩余 10 天启动 | 状态「即将到期」，进入主界面后标题显示剩余天数 |
| A-04 | 把系统时间调早 1 天 | 判定「授权异常」并锁定 |
| A-05 | 授权目录无写权限 | 回退到可写目录，功能不中断 |

A-02 已由界面自动化 `tests/MultiStation.Ui.Smoke`（M-04）覆盖；A-01、A-03、A-04 由逻辑测试覆盖；A-05 由 `LogPaths` / 安全目录回退机制验证。
边界值由 B-L01 ~ B-L08 覆盖（剩余 16/15/0 天、过期 1 秒、回拨 9/11 分钟、授权文件损坏与缺字段）与 U-B02（剩余 1 分钟启动），结果见 [90_冒烟测试报告](90_冒烟测试报告_定时锁与权限登入.md)。
