# 权限登入

- 所属模块：`MultiStation.Platform`（子模块 `MultiStation.Platform.Security`）
- 功能编号段：F-AUTH-01 ~ F-AUTH-11
- 当前状态：已验收

## 一、功能清单

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| F-AUTH-01 | 首次初始化注册 | 无任何账号时弹出注册窗口，由用户自行创建唯一管理员，代码不预置账号 | 已验收 |
| F-AUTH-02 | 启动登录 | 已有账号时弹出登录窗口，取消或关闭则退出程序 | 已验收 |
| F-AUTH-03 | 密码存储与校验 | 盐 + SHA256 摘要比对，不存明文；比较使用固定时间算法 | 已验收 |
| F-AUTH-04 | 角色与会话 | 登录成功生成 `UserSession`，供全程序判断权限 | 已验收 |
| F-AUTH-05 | 权限矩阵 | Operator / Engineer / Admin 三级，按权限点授权 | 已验收 |
| F-AUTH-06 | 操作拦截 | 无权限的操作弹提示并拒绝执行，不改变任何状态 | 已验收 |
| F-AUTH-07 | 失败次数限制 | 同一窗口连续失败 5 次后禁止继续尝试，需重启软件 | 已验收 |
| F-AUTH-11 | 调试权限限时屏蔽 | 管理员可临时跳过权限校验（分钟/小时/天/周/月，单次最长 90 天）；有效期内重启免登录进入，到期自动恢复，全程写审计 | 已实现（调试） |

## 二、首次运行流程

```
启动 → 授权校验
     ├─ 未通过 → 锁定窗口 → 退出
     └─ 通过 → 是否存在账号？
             ├─ 否 → 注册管理员（用户名 + 密码 + 确认密码）→ 创建成功即登录
             └─ 是 → 登录窗口 → 校验通过进入主界面
```

| 项 | 规则 |
|---|---|
| 账号文件 | `users.json`，位于与 `license.json` 相同的安全目录 |
| 初始化条件 | 文件不存在或账号数为 0 |
| 只允许一次 | 已存在账号时再次初始化会被拒绝，防止绕过登录重置权限 |
| 用户名 | 3~32 位，允许字母、数字与 `_ - .` |
| 密码 | 至少 8 位，必须同时包含字母与数字 |
| 重置方式 | 管理员删除 `users.json` 后重启软件重新初始化，该操作需人工授权 |

## 三、角色与权限矩阵

| 权限点 | 含义 | Operator | Engineer | Admin |
|---|---|---|---|---|
| `Operate` | 启停测试、暂停、单步、投料、复位故障、导出结果 | 允许 | 允许 | 允许 |
| `Configure` | 修改字段配置、配方、序列 | 拒绝 | 允许 | 允许 |
| `ManageUsers` | 账号管理、审计查看 | 拒绝 | 拒绝 | 允许 |

角色数值越大权限越高（Operator=1，Engineer=2，Admin=3），Admin 默认拥有全部权限。

## 四、已接入的权限拦截点

| 界面操作 | 权限点 | 文件位置 |
|---|---|---|
| 开始测试 / 暂停 / 停止 / 单步 | Operate | `MainWindow.xaml.cs` |
| 手动投料 | Operate | `MainWindow.xaml.cs` |
| 复位故障 | Operate | `MainWindow.xaml.cs` |
| 导出结果 CSV | Operate | `MainWindow.xaml.cs` |
| 字段配置 | Configure | `MainWindow.xaml.cs` |

拦截实现为统一入口 `RequirePermission(Permission)`：无权限时弹窗提示「权限不足」，直接返回，不执行任何业务动作。

## 五、调试权限限时屏蔽

仅用于调试：临时跳过权限校验，避免反复切换账号。

| 项 | 规则 |
|---|---|
| 入口 | 主界面右上角「调试屏蔽」，仅 Admin 可打开；该入口校验角色本身，不受屏蔽影响，避免自我提权 |
| 时长 | 支持分钟 / 小时 / 天 / 周 / 月五种单位（月按 30 天折算），单次最长 90 天，到期自动恢复 |
| 原因 | 必填，随开启记录写入审计 |
| 生效范围 | 屏蔽期间跳过权限校验；有效期内重启则免登录，直接以「调试屏蔽（Admin）」会话进入 |
| 界面提示 | 顶部橙色横幅「权限屏蔽中 剩余 …：权限校验已放行；原因：…」，右上角按钮变「屏蔽中」；超过 1 天显示「N天 hh:mm:ss」 |
| 审计 | 安全目录下 `debug-bypass.log`，记录开启 / 关闭 / 到期 / 重启恢复、操作者与原因 |
| 生命周期 | 持久化到安全目录 `debug-bypass.json`，到期或关闭时自动删除；超过 90 天或文件损坏视为无效并清除 |
| 实现 | `MultiStation.Platform.Security/PermissionBypass.cs`、`Ui.Desktop/DebugBypassWindow.xaml` |

## 六、验收标准

| 编号 | 场景 | 期望 |
|---|---|---|
| A-01 | 首次运行（无 users.json） | 弹出注册窗口，创建成功后直接进入主界面 |
| A-02 | 注册时两次密码不一致 | 提示不一致，停留在注册窗口 |
| A-03 | 注册弱密码（少于 8 位或纯字母） | 拒绝并说明密码规则 |
| A-04 | 已存在账号后再次尝试初始化 | 拒绝，提示已存在账号 |
| A-05 | 正确账号密码登录 | 进入主界面，标题显示账号与角色 |
| A-06 | 错误密码登录 | 提示失败次数，不进入主界面 |
| A-07 | 连续失败 5 次 | 禁止继续尝试，提示重启软件 |
| A-08 | Operator 点击「字段配置」 | 弹「权限不足」，配置菜单不弹出 |
| A-09 | Engineer 点击「字段配置」 | 正常弹出配置菜单 |
| A-10 | 取消注册或登录 | 程序退出，不创建主窗口、不启动产线 |
| A-11 | 冒烟模式 `--smoke` | 跳过登录交互，以 Admin 会话运行；启动测试前仍需人工确认 |
| A-12 | Operator 点击「调试屏蔽」 | 弹「权限不足（仅限管理员）」，不弹出屏蔽窗口 |
| A-13 | Admin 开启 2 天屏蔽 | 顶部显示「1天23:xx:xx」剩余时间、按钮变「屏蔽中」；再次进入关闭后状态清空 |
| A-14 | 屏蔽到期 / 超限 / 原因为空 | 到期自动恢复；超过 90 天、时长≤0 或原因为空均拒绝开启 |
| A-15 | 屏蔽有效期内重启软件 | 免登录直接进入主界面，标题含「免登录调试」，顶部显示橙色屏蔽横幅 |
| A-16 | 持久化文件已到期 / 超过 90 天 / 损坏 | 不恢复屏蔽，按普通流程登录，并自动删除 `debug-bypass.json` |

其中 A-02、A-07、A-08 已由 `tools/MultiStation.Ui.Smoke` 界面自动化覆盖（对应报告 M-01 ~ M-03），其余为手工用例。
边界值由 B-A01 ~ B-A14 覆盖（用户名 2/3/32/33 位、trim、合法字符、密码 7/8 位、组成约束、空凭据、大小写登录）与 U-B01（失败 4 次后成功）、U-B03/U-B04（注册界面上下限）、U-B05（Engineer 角色边界），结果见 [90_冒烟测试报告](90_冒烟测试报告_定时锁与权限登入.md)。
调试屏蔽由 BP-01 ~ BP-14（时长上下限与 90 天边界、周折算、原因必填、关闭、到期恢复、审计、角色不被提权、持久化写入/删除/恢复/过期与超限清除）与 U-BP01 / U-BP02 / U-BP03（Operator 拒绝、Admin 以「天」为单位开启与关闭、免登录重启）覆盖，随同套件执行，`SUMMARY failures=0`。
