# 质量与验收规则

适用范围：架构与实现的验收口径。所有数值为出厂门槛，低于门槛不通过验收。

## 一、解耦

| 编号 | 规则 | 目标值 | 采集方式 | 级别 |
|---|---|---|---|---|
| Q-01 | 模块间直接引用数 | 0 | Roslyn 分析器（编译期强制） | 阻断 |
| Q-02 | 模块对契约族之外的依赖 | 0 | 编译期检查 | 阻断 |
| Q-03 | 执行循环内阻塞调用数 | 0 | 分析规则 + 代码审查 | 阻断 |
| Q-04 | 新增一个模块的改动文件数 | ≤ 2（契约 + 组合根） | 代码评审 | 强制 |

## 二、性能

| 编号 | 规则 | 目标值 | 采集方式 | 级别 |
|---|---|---|---|---|
| Q-05 | 入队到出队延迟 P99 | ≤ 1ms | Core 调度指标 | 强制 |
| Q-06 | 端到端处理延迟 P99（不含设备 IO） | ≤ 5ms | Core 处理指标 | 强制 |
| Q-07 | 单次投递开销 | ≤ 50µs，零分配 | BenchmarkDotNet | 强制 |
| Q-08 | Background 最长等待 | ≤ 2s（老化生效） | 老化统计 | 强制 |
| Q-09 | 低优先级饥饿次数 | 0 | 配额公平计数器 | 强制 |
| Q-10 | 多工位共享设备等待偏差 | ≤ 20% | 来源公平统计 | 强制 |

## 三、可靠性

| 编号 | 规则 | 目标值 | 采集方式 | 级别 |
|---|---|---|---|---|
| Q-11 | 结果丢失条数（异常断电） | 0 | WAL 重放校验 | 阻断 |
| Q-12 | 重复执行次数（重放） | 0 | 幂等表校验 | 阻断 |
| Q-13 | 事件版本跳号次数（稳态） | 0 | resync 计数 | 强制 |
| Q-14 | 死信数量（稳态） | 0 | DLQ 监控 | 强制 |
| Q-15 | 模块启动失败回滚率 | 100% | 启动自检用例 | 强制 |

## 四、安全

| 编号 | 规则 | 说明 | 级别 |
|---|---|---|---|
| Q-16 | 急停由硬件回路完成 | 软件断输出仅为附加措施 | 阻断 |
| Q-17 | 安全状态位读取周期 ≤ 20ms | 不依赖队列长度与线程池状态 | 阻断 |
| Q-18 | 安全状态只能硬件恢复 | 软件任何角色不可复位 | 阻断 |
| Q-19 | Post 必达且含关输出 | 见 T-04、V-13 | 阻断 |

## 五、链路预算

| 环节 | 目标 | 上限 |
|---|---|---|
| UI 点击 → Core 入队 | 0.3ms | 1ms |
| Core 路由 → 模块出队 | 0.5ms | 1ms |
| 模块处理（不含设备 IO） | 2ms | 5ms |
| 结果 → WAL 落盘确认 | 3ms | 10ms |
| 整链（点击到状态刷新） | 15ms | 50ms |

设备往返必须单独统计，不得混入总线预算。

## 六、验收方式

| 阶段 | 验收内容 | 通过条件 |
|---|---|---|
| 编译期 | 分析器规则全绿 | 0 警告、0 错误 |
| 单元测试 | 模块契约测试、优先级与取消行为 | 全部通过 |
| 架构测试 | 引用矩阵为空 | 0 违规 |
| 集成测试 | 双跑比对（旧路径 vs 新总线） | 差异为 0 |
| 压测 | 延迟、积压、丢弃、公平性 | 全部达标 |
| 现场验收 | 断电重启、Post 必达、End 关闭 | 结果不丢、仪器无残留输出 |

## 七、指标口径

| 指标 | 口径定义 |
|---|---|
| 入队到出队 | 消息进入目标信箱到被模块取出的时间 |
| 端到端处理 | 出队到处理完成的时间，不含设备 IO |
| 链路端到端 | 按 traceId 从发起到最终状态的时间 |
| 饥饿 | Control 消息因低优先级插队而延迟的累计次数 |
| 公平偏差 | 同一设备各来源平均等待时间的最大偏差比例 |
